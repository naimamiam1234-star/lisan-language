# إضافة محرّر Visual Studio Code للغة لسان

توفر هذه النسخة الأولية تمييزًا نحويًا لامتداد `.lsn` ومقاطع جاهزة للأوامر. لا تتضمن خادم لغة LSP أو مصحح أخطاء.

لاختبارها: افتح مجلد `editors/vscode` في VS Code، واضغط `F5` لتشغيل Extension Development Host.
