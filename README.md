# لسان — LISAN 0.3.0 (نسخة مصدرية تجريبية)

**لسان** مشروع لإنشاء لغة برمجة عربية مستقلة، بنواة مكتوبة بلغة **Rust**. هذه النسخة **مفسّر** (Interpreter) يقرأ وينفذ برامج `.lsn`، وليست مترجمًا ينتج ملفات تنفيذية من شيفرة لسان.

## الجديد في الإصدار 0.3.0

- استيراد الملفات: `استورد "مسار/وحدة.lsn"؛`، بالنسبة إلى موقع الملف المصدر.
- اكتشاف الاستيراد الدائري، وعدم تحميل الوحدة المكررة أكثر من مرة، ورسائل خطأ تذكر الملف.
- أمر فحص القواعد والاستيرادات دون تنفيذ: `cargo run -- --check examples/modules/main.lsn`.
- مزيد من الاختبارات، ومثال متعدد الملفات في `examples/modules/`.

## ميزات 0.2.0

- **قوائم** مختلطة الأنواع: `[١، "نص"، صحيح]`، مع القوائم المتداخلة.
- **فهرسة** قائمة أو نص من الصفر: `س[٠]` و`س[١][٠]`.
- **إسناد عنصر قائمة** موجودة مباشرة عبر متغير: `س[١] = ١٠؛`.
- **حلقة لكل**: `لكل (عنصر في قائمة) { ... }`، وتعمل أيضًا مع الأحرف العربية في النصوص.
- عمليات منطقية بالعربية: `و` / `أو` / `ليس` إلى جانب `&&` / `||` / `!`.
- **دوال قياسية أولية**: `طول` و`نوع` و`نص` و`عدد` و`أضف` و`مدى` و`يحتوي`.
- دعم ربط قائمتين باستخدام `+`، واختبارات إضافية للحالات العادية والأخطاء.

## ما تدعمه النواة أصلًا

معرفات UTF-8 وكلمات عربية، وأعداد ١٢٣ و۱۲۳ و123، ونصوص وقيم منطقية، وتعليقات، ومتغيرات، وعمليات حسابية، وشروط وحلقات `طالما`، ودوال عادية واستدعاء ذاتي، وقواعد نطاقات محلية، ورسائل أخطاء عربية وبيئة REPL بسيطة.

## مثال سريع

```lisan
دع الأعداد = [١، ٢، ٣]؛
الأعداد[١] = ٥؛
الأعداد = أضف(الأعداد، ٨)؛
دع مجموع = ٠؛
لكل (عنصر في الأعداد) {
    مجموع = مجموع + عنصر؛
}
اطبع("المجموع: " + مجموع)؛
اطبع("عدد العناصر: " + طول(الأعداد))؛
```

الناتج المتوقع:

```text
المجموع: 17
عدد العناصر: 4
```

## البناء والتشغيل

تتطلب النسخة **Rust/Cargo**. تثبيتها الرسمي: https://rustup.rs/ . على Ubuntu/macOS أو Windows PowerShell، افتح الطرفية في مجلد المشروع وشغّل:

```bash
cargo --version
cargo test
cargo build --release
cargo run -- examples/hello.lsn
cargo run -- examples/lists.lsn
cargo run -- examples/text.lsn
cargo run -- examples/modules/main.lsn
cargo run -- --check examples/modules/main.lsn
cargo run -- -e 'اطبع("أهلاً بلغة لسان")؛'
```

ناتج البناء: `target/release/lisan` في Linux/macOS أو `target\release\lisan.exe` في Windows.

البيئة التفاعلية: `cargo run` ثم إدخال أوامر تامة في كل سطر؛ `خروج` للإغلاق.

## تنزيل المفسّر الجاهز

عند نجاح GitHub Actions، افتح تشغيل `Rust CI` في تبويب Actions ثم نزّل الحزمة من قسم Artifacts (`lisan-Windows` أو `lisan-Linux` أو `lisan-macOS`). حزمة Windows تحتوي `lisan.exe`؛ وحزم لينكس/ماك تحتوي الملف التنفيذي `lisan`. هذه برامج **لتفسير ملفات لسان**، وليست ملفات تنفيذية مولّدة من شيفرة لسان نفسها.

## وضع التحقق في بيئة الإنشاء

تُشغّل اختبارات Rust تلقائيًا عبر GitHub Actions على لينكس وويندوز وماك. راجع نتائج التشغيل من تبويب Actions؛ البناء المحلي يحتاج تثبيت Rust.

## الحدود الحالية

- التنفيذ تفسيري، وليس هناك LLVM أو Cranelift أو ملف تنفيذي مستقل ناتج عن شيفرة لسان.
- لا يوجد مدير حزم أو شبكة أو واجهات رسومية. الاستيراد الحالي يدمج ملفات لسان النصية ولا يقدم نطاقات وحدات معزولة أو مكتبات ديناميكية.
- لا يوجد نظام أنواع ثابت أو إدارة ذاكرة إنتاجية؛ القيم العددية ممثلة بواسطة `f64`.
- الفهرسة تبدأ من **الصفر**؛ تغيير عنصر قائمة عبر `س[فهرس] = قيمة؛` يدعم الهدف المباشر فقط، وليس `س[٠][١] = ...`.
- `أضف(القائمة، عنصر)` **تعيد قائمة جديدة**؛ خزّنها بإسناد إذا أردت حفظ الإضافة.
- `مدى(بدء، نهاية)` ينتج الأعداد من البدء إلى ما قبل النهاية، ولا ينتج قائمة تنازلية.
- الحد الآمن التقريبي للقائمة 10,000 عنصر، ولتنفيذ البرنامج 250,000 خطوة، ولعمق الاستدعاء 128؛ هذه ليست آلية حماية أمنية من برامج خبيثة.
- REPL أحادي الأسطر للتعليمات المكتملة؛ الدوال متعددة الأسطر توضع في `.lsn`.

## خارطة الطريق

1. تشغيل CI فعليًا، مراجعة الأخطاء، اختبارات أوسع وقرارات اللغة الأساسية.
2. مكتبة قياسية ووحدات واستيراد، وأدوات حزم واختبارات ومعالجة أخطاء أفضل.
3. تمثيل وسيط IR، وتحليل أنواع، ثم اختيار خلفية LLVM/Cranelift أو آلة افتراضية.
4. إنتاج ملفات تنفيذية على Linux وWindows وmacOS، وبعدها واجهات C وFFI.
5. نظام أدوات التطوير، وتحرير الكود بذكاء، ومكتبات واجهات رسومية وبرمجة مدمجة.
