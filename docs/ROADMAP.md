# خارطة طريق لسان — تقاس بالميزات لا بأرقام الإصدارات

## تحققنا منه عبر GitHub CI

- لغة مكتوبة بـ Rust ومفسّر واختبارات وأمثلة وحزم مفسّر للأنظمة الثلاثة في إصدارات سابقة.

## الإصدار 0.4 — ما استهدفه هذا التحديث

- أرقام لاتينية 0-9 مع رسائل خطأ عند استعمال الأرقام العربية أو الفارسية في الشيفرة.
- أوامر عربية فصيحة، قواميس ودوال قياسية إضافية، قراءة وكتابة الملفات.
- أوامر `--tokens` و`--ast`، وإضافة VS Code أولية، وأمثلة واختبارات جديدة.

## مراحل لاحقة تتطلب تصميمًا واختبارات منفصلة

- مترجم bytecode وآلة افتراضية وإدارة ذاكرة أدق وقياسات أداء.
- ثوابت وأنواع ثابتة وتحليل معنوي، وإغلاق دوال وقواعد وحدات كاملة.
- مكتبة شبكات وواجهات وأدوات اختبار وتصحيح أخطاء وأمان صلاحيات.
- مولّد شيفرة/LLVM أو Cranelift وإنتاج ملفات EXE/ELF/Mach-O من شيفرة لسان.
- مدير حزم، وخادم لغة LSP، وإضافة VS Code كاملة، وواجهات GUI، واستهداف الأجهزة المضمنة.

ليست أرقام الإصدارات مثل 1999 معيارًا لاكتمال هذه الوظائف. نعتمد اكتمال الميزات ونجاح الاختبارات.

## خطوة 0.5: حزم البرامج

- دعم `lisan --build برنامج.lsn --output app` لإنشاء ملف تنفيذي يحتوي AST بعد حل الاستيرادات ومفسّر لسان.
- يحتاج Rust/Cargo أثناء البناء فقط.
- ليس بعد مترجمًا أصليًا محسّنًا مثل LLVM، ولا ينتج ملفًا عابرًا للمنصات: ابنِ على النظام المستهدف.
