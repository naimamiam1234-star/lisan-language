# تحويل برنامج لسان إلى ملف تنفيذي مستقل

بناء البرنامج على Windows وLinux وmacOS:

```bash
cargo run -- --build examples/modules/main.lsn --output my-application
```

في Windows استخدم `--output my-application.exe`. يمكن أيضًا استخدام المفسّر الجاهز عند توفر `cargo` على الجهاز:

```bash
lisan --build main.lsn --output my-application
```

أثناء البناء تُقرأ الاستيرادات وتُحلّ إلى AST، ثم يُنشئ Rust/Cargo ملفًا تنفيذيًا يحوي نسخة من المفسّر وبرنامجك. **ليس هذا مترجمًا مباشرًا إلى تعليمات المعالج**. التشغيل لا يحتاج Cargo أو ملف `.lsn` الأصلي؛ لكن التعامل مع ملفات خارجية باستخدام `اقرأ_ملف` أو `اكتب_ملف` يظل يعتمد على مسار التنفيذ وصلاحيات نظام التشغيل. التطبيق الناتج يعمل فقط على نوع النظام والمعمارية التي بُني عليها؛ لا يوجد cross-compilation تلقائي. يحتفظ المفسّر بحدود التنفيذ والحجم الموجودة حاليًا.

إذا وجدت رسالة `تعذر تشغيل Cargo` فيجب تثبيت Rust/Cargo أولًا. إن كان ملف الناتج موجودًا من قبل، يُرفض استبداله لحماية ملفات المستخدم.
