# النصوص الأصلية المُدارة — معاينة 0.9

يضيف مسار الأنواع الأصلي للمضيف x86_64 نصوص UTF-8 مملوكة مع عدّ مراجع وتحرير للذاكرة. التنفيذ LLVM وبيئة C أصلية، ولا يتضمن مفسّرًا.

اختيار المسار بصياغة `ليكن رسالة: نص = "مرحبًا"؛`. العمليات: النسخ والإسناد و`+` و`==` و`!=` و`طول(رسالة)` والفهرسة `رسالة[0]` والطباعة. طول النص يعيد `ط64`، ويعد Unicode scalars؛ طول `"سَ😀"` هو3. يبدأ الفهرس من0 ويعيد نصًا من scalar واحد. لا يوجد تطبيع Unicode أو تجميع العناقيد المرئية. محرف NUL صالح ولا يوقف الطباعة أو المساواة.

الواصف الداخلي `{size_t byte_len; const unsigned char *data;}`. تمرر دوال البيئة مؤشرات إلى الواصفات لتجنب اختلاف ABI المركبات بين Windows وLinux. الجمع والفهرسة ينشئان قيمة مملوكة، والنسخ يزيد المرجع بعد فحص الفيض. يحرر المترجم المؤقتات بعد التعليمة والمتغيرات عند نهاية النطاق. الإسناد يجهز القيمة الجديدة قبل تحرير القديمة، بما يشمل الإسناد إلى النفس. تُقيّم المعاملات من اليسار إلى اليمين، وتُحفظ قيمة الطرف الأيسر حتى إذا أعاد الطرف الأيمن إسناد متغيره. فشل التخصيص لا يغير القيم الأصلية. تحرير القيم لا يخصص ذاكرة. عند فشل البرنامج، يشمل التنظيف النصوص الحية حتى إن وقع خطأ عددي داخل دالة مستدعاة.

تدعم هذه الدفعة النصوص المُدارة في المستوى الأعلى والكتل والشروط والحلقات، وفي معاملات دوال لسان ونتائجها وأجسامها، بما يشمل الاستدعاء الذاتي والإرجاع المبكر. يملك كل استدعاء واصفاته المحلية المستقلة. تحفظ وسائط النص من اليسار إلى اليمين قبل تقييم الوسيط التالي؛ ويمتلك المعامل المحلي نسخة مرجعية مستقلة، فيمكن إسناده دون تغيير قيمة المستدعي. تنسخ النتيجة إلى واصف مملوك للمستدعي قبل تحرير إطار الدالة. القوائم والقواميس المُدارة ليست ضمن هذه الدفعة.

هذه معاينة للمضيف: تستخدم سياقًا واحدًا للبرنامج وسجلًا مرتبطًا للإطارات النشطة على المكدس. يسجل كل إطار واصفات صفرية قبل أول عملية قابلة للفشل، ويلغي تسجيله قبل الإرجاع. ينظف الفشل جميع الإطارات ثم السياق ويطبع الخطأ المحدد بالمصدر وينهي العملية. تبقى واجهة الدوال العددية كما هي؛ تستخدم نتيجة النص مؤشر خرج داخليًا مخفيًا، وليست واجهة C عامة. لم تنفذ بعد قناة الحالة القابلة للاسترداد وحساب آثار الدوال المخططان في خطة القيم المُدارة. لا يدعم هذا المسار إعادة الدخول من C أو التنفيذ المتزامن، ويرفض تصدير مكتبة تستخدم النص المدار، وكذلك دوال C المصدرة في برنامج يستخدم هذا المسار ولو كان توقيعها عدديًا.

لا يسمح بنص مُدار في توقيع C أو مؤشر إلى نص أو عنوان خام للنص، ولا تحويل ضمني إلى C string. الفهارس تقبل أنواع الأعداد الصحيحة أو float منتهيًا وصحيح القيمة وغير سالب وأقل من2^64، مع فحص الحدود قبل الوصول إلى الذاكرة.

مصادر البيئة مضمّنة في المترجم ويجهّزها ويربطها Clang تلقائيًا عند بناء برنامج يستخدم النصوص المُدارة؛ لا تحتاج نسخة المترجم الموزعة إلى شجرة المصادر. الملف التنفيذي الناتج مستقل عن المترجم. عند حفظ LLVM وحده يلزم ربطه يدويًا مع `runtime/common/value.c` و`runtime/host/allocator.c` وترويسة `runtime/common/value.h` من النسخة المطابقة، مع `-Iruntime/common`.

دعم Arduino وWebAssembly وإدارة ذاكرتهما يحتاج تنفيذًا واختبارات منفصلة؛ لا يثبت باختبارات المضيف.

## تنظيف الشروط والحلقات

تحرر مؤقتات شرط `إذا` و`بينما` بعد حساب النتيجة وقبل دخول الفرع أو جسم الحلقة، بما يشمل التقييم الأخير الذي ينهي الحلقة. تنتهي حياة متغيرات الفرع عند الخروج منه، ومتغيرات جسم الحلقة عند كل نهاية دورة. يحرر `توقف` و`تابع` مؤقتات التعليمة والمتغيرات المحلية حتى نطاق الحلقة المعنية، مع إبقاء متغيرات الحلقات الخارجية والمستوى الأعلى حية. ينظف مسار الفشل جميع النصوص المتبقية.

ينفذ `و` و`أو` الطرف الأيمن فقط عند الحاجة؛ لذلك لا يخصص نصًا ولا يفهرسه إن تخطى تقييمه. يمكن أن تبقى المؤقتات المنفذة حية حتى نهاية التعبير الذي يحتويها، ثم تحرر عند نهاية التعليمة أو شرط التحكم. الحلقات ذات عبء العمل الثابت الحجم تعيد استخدام واصفات فارغة ولا تراكم تخصيصات من الدورات السابقة؛ النص الذي يكبر عمدًا يبقى بحاجة إلى ذاكرة تناسب حجمه.
