# القيم الأصلية المُدارة — معاينة 0.9

يضيف مسار الأنواع الأصلي للمضيف x86_64 نصوص UTF-8 مملوكة مع عدّ مراجع وتحرير للذاكرة. التنفيذ LLVM وبيئة C أصلية، ولا يتضمن مفسّرًا.

اختيار المسار بصياغة `ليكن رسالة: نص = "مرحبًا"؛`. العمليات: النسخ والإسناد و`+` و`==` و`!=` و`طول(رسالة)` والفهرسة `رسالة[0]` والطباعة. طول النص يعيد `ط64`، ويعد Unicode scalars؛ طول `"سَ😀"` هو3. يبدأ الفهرس من0 ويعيد نصًا من scalar واحد. لا يوجد تطبيع Unicode أو تجميع العناقيد المرئية. محرف NUL صالح ولا يوقف الطباعة أو المساواة.

الواصف الداخلي `{size_t byte_len; const unsigned char *data;}`. تمرر دوال البيئة مؤشرات إلى الواصفات لتجنب اختلاف ABI المركبات بين Windows وLinux. الجمع والفهرسة ينشئان قيمة مملوكة، والنسخ يزيد المرجع بعد فحص الفيض. يحرر المترجم المؤقتات بعد التعليمة والمتغيرات عند نهاية النطاق. الإسناد يجهز القيمة الجديدة قبل تحرير القديمة، بما يشمل الإسناد إلى النفس. تُقيّم المعاملات من اليسار إلى اليمين، وتُحفظ قيمة الطرف الأيسر حتى إذا أعاد الطرف الأيمن إسناد متغيره. فشل التخصيص لا يغير القيم الأصلية. تحرير القيم لا يخصص ذاكرة. عند فشل البرنامج، يشمل التنظيف النصوص الحية حتى إن وقع خطأ عددي داخل دالة مستدعاة.

تدعم هذه الدفعة النصوص المُدارة في المستوى الأعلى والكتل والشروط والحلقات، وفي معاملات دوال لسان ونتائجها وأجسامها، بما يشمل الاستدعاء الذاتي والإرجاع المبكر. يملك كل استدعاء واصفاته المحلية المستقلة. تحفظ وسائط النص من اليسار إلى اليمين قبل تقييم الوسيط التالي؛ ويمتلك المعامل المحلي نسخة مرجعية مستقلة، فيمكن إسناده دون تغيير قيمة المستدعي. تنسخ النتيجة إلى واصف مملوك للمستدعي قبل تحرير إطار الدالة. القوائم المتجانسة ذات العناصر العددية والمنطقية والنصية مدعومة أيضًا؛ القوائم المتداخلة والقواميس المُدارة ليست ضمن هذه الدفعة.

هذه معاينة للمضيف: تستخدم سياقًا واحدًا للبرنامج وسجلًا مرتبطًا للإطارات النشطة على المكدس. يسجل كل إطار واصفات صفرية قبل أول عملية قابلة للفشل، ويلغي تسجيله قبل الإرجاع. ينظف الفشل جميع الإطارات ثم السياق ويطبع الخطأ المحدد بالمصدر وينهي العملية. تبقى واجهة الدوال العددية كما هي؛ تستخدم نتيجة النص مؤشر خرج داخليًا مخفيًا، وليست واجهة C عامة. لم تنفذ بعد قناة الحالة القابلة للاسترداد وحساب آثار الدوال المخططان في خطة القيم المُدارة. لا يدعم هذا المسار إعادة الدخول من C أو التنفيذ المتزامن، ويرفض تصدير مكتبة تستخدم النص المدار، وكذلك دوال C المصدرة في برنامج يستخدم هذا المسار ولو كان توقيعها عدديًا.

لا يسمح بنص مُدار في توقيع C أو مؤشر إلى نص أو عنوان خام للنص، ولا تحويل ضمني إلى C string. الفهارس تقبل أنواع الأعداد الصحيحة أو float منتهيًا وصحيح القيمة وغير سالب وأقل من2^64، مع فحص الحدود قبل الوصول إلى الذاكرة.

مصادر البيئة مضمّنة في المترجم ويجهّزها ويربطها Clang تلقائيًا عند بناء برنامج يستخدم النصوص المُدارة؛ لا تحتاج نسخة المترجم الموزعة إلى شجرة المصادر. الملف التنفيذي الناتج مستقل عن المترجم. عند حفظ LLVM وحده يلزم ربطه يدويًا مع `runtime/common/value.c` و`runtime/host/allocator.c` وترويسة `runtime/common/value.h` من النسخة المطابقة، مع `-Iruntime/common`.

دعم Arduino وWebAssembly وإدارة ذاكرتهما يحتاج تنفيذًا واختبارات منفصلة؛ لا يثبت باختبارات المضيف.

## تنظيف الشروط والحلقات

تحرر مؤقتات شرط `إذا` و`بينما` بعد حساب النتيجة وقبل دخول الفرع أو جسم الحلقة، بما يشمل التقييم الأخير الذي ينهي الحلقة. تنتهي حياة متغيرات الفرع عند الخروج منه، ومتغيرات جسم الحلقة عند كل نهاية دورة. يحرر `توقف` و`تابع` مؤقتات التعليمة والمتغيرات المحلية حتى نطاق الحلقة المعنية، مع إبقاء متغيرات الحلقات الخارجية والمستوى الأعلى حية. ينظف مسار الفشل جميع النصوص المتبقية.

ينفذ `و` و`أو` الطرف الأيمن فقط عند الحاجة؛ لذلك لا يخصص نصًا ولا يفهرسه إن تخطى تقييمه. يمكن أن تبقى المؤقتات المنفذة حية حتى نهاية التعبير الذي يحتويها، ثم تحرر عند نهاية التعليمة أو شرط التحكم. الحلقات ذات عبء العمل الثابت الحجم تعيد استخدام واصفات فارغة ولا تراكم تخصيصات من الدورات السابقة؛ النص الذي يكبر عمدًا يبقى بحاجة إلى ذاكرة تناسب حجمه.

مثال كامل: [النصوص مع الشروط والحلقات](../examples/native_text_control.lsn).

## القوائم المتجانسة للمضيف

```text
متغير أ: قائمة<ص32> = [1, 2]؛
متغير ب = أ؛
ب[0] = 9؛
أضف(ب, 3)؛
اطبع(أ[0])؛ // 1
اطبع(طول(ب))؛ // 3
```

تقبل `قائمة<T>` جميع الأنواع الصحيحة بعرض8 و16 و32 و64، و`ع32` و`ع64` و`منطقي` و`نص`. تستنتج القائمة غير الفارغة نوعًا واحدًا؛ يحدد السياق نوع الثوابت العددية، أو يحددها عنصر غير ثابت ذي نوع معروف. الأعداد غير المقيدة بسياق تبقى `ع64`. تحتاج `[]` سياقًا مثل `متغير أ: قائمة<نص> = []` أو معامل دالة ذي نوع قائمة. الأنواع المختلطة، العناصر المؤشرية و`فراغ`، والقوائم المتداخلة مرفوضة بتشخيص. لا تدعم هذه الدفعة طباعة القائمة كاملة أو حذف عنصر أو foreach؛ يمكن طباعة عناصرها المدعومة.

`طول` يعيد `ط64` ويعد العناصر. الفهرسة تبدأ من0 وتعيد نسخة قيمة العنصر. `==` و`!=` يقارنان ترتيب العناصر ومحتواها؛ النصوص حسب بايتاتها، والأنواع العائمة حسب المساواة العددية. ليس تساوي عنوان التخزين معيارًا للمساواة. يغير `ب[ف] = قيمة` و`أضف(ب, قيمة)` المتغير المسمى وحده. تحافظ النسخ على دلالات القيمة؛ تجهز كل طفرة تخزينًا منفصلًا ثم تستبدل المرجع بعد النجاح، حتى إن كان المرجع فريدًا. هذه سياسة نسخ عند التعديل محافظة؛ تكلفة الطفرة خطية في طول القائمة ولا تدعي تحسين السعة أو التعديل في المكان.

تؤخذ نسخة مرجعية لهدف الطفرة أولًا، ثم يقيم الفهرس والقيمة مرة واحدة من اليسار إلى اليمين. إذا أعاد الفهرس أو الطرف الأيمن إسناد الهدف، تطبق الطفرة النهائية على النسخة الملتقطة أولًا. تحفظ عناصر literals ووسائط الدوال قبل تقييم العنصر/الوسيط اللاحق الذي قد يعيد إسناد متغير سابق. فشل البيئة لا ينشر قائمة جزئية؛ لا تعني هذه الضمانة التراجع عن الآثار الجانبية المكتملة أثناء تقييم تعبير المصدر، فالخطأ ينهي البرنامج.

تدعم القوائم معاملات دوال لسان ونتائجها والاستدعاء الذاتي والشروط والحلقات والإرجاع المبكر. التمثيل الداخلي خانة تحتوي مؤشر تخزين معتمًا؛ واصف العنصر ثابت ومحلي للهدف. سجل الإطار يحمل لكل خانة دالة التحرير المناسبة للنص أو القائمة. تُحرر عناصر النص عند تحرير آخر مرجع للقائمة. لا تخصص عملية التحرير ذاكرة، ولا توجد دورة ملكية لأن العناصر المتداخلة غير مدعومة بعد. تعيد نتيجة القائمة مرجعًا مملوكًا إلى خانة المستدعي، ويطبق الفشل المحدد بالمصدر تنظيف جميع الإطارات نفسه المستخدم للنصوص.

لا تسمح واجهة C بقائمة أو مؤشر إلى قائمة أو عنوان/تحميل/تخزين خام لقائمة. تبقى قيود المضيف والسياق الواحد وعدم إعادة الدخول والتصدير وغياب قناة الخطأ القابلة للاسترداد قائمة. استخدام `قائمة<T>` يختار المسار المحدد بالأنواع دون مفسر أو fallback؛ البرامج القديمة الخالية من الصياغة المحددة بالأنواع تحتفظ بمسار قوائم الأرقام القديم ولا تحول تمثيله ضمنيًا.

التحقق: `tests/native_managed_collections.rs` يغطي أنواع العناصر والنسخ والطفرة والنتائج والاستدعاء الذاتي وترتيب التقييم وفشل كل تخصيص وتنظيف الإطارات مع عدّ التخصيصات الحية؛ `tests/fixtures/managed/list_harness.c` يغطي فيض الأحجام والمراجع والمخرجات غير المعدلة والتراجع عن النسخ الجزئي والتحرير دون تخصيص. هذا إثبات مضيف؛ لا يثبت دعم المتصفح أو الهدف الحر أو المجموعات المتداخلة.

تحتفظ الدالة المعلنة باسم `طول` أو `أضف` بحل اسمها المعتاد؛ تستخدم العملية المضمنة فقط عند غياب تصريح بهذا الاسم. `أضف` في هذا المسار تغير المتغير المسمى وتعيد `فراغ`؛ تختلف عن builtin التوافق القديم الذي يعيد قائمة منسوخة. لا يغير ذلك سلوك البرنامج القديم تلقائيًا.
