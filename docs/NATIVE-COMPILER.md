# مترجم لسان الأصلي (التطوير الأول)

**المطلوب:** Rust وCargo لبناء أداة `lisan`، وClang لإنشاء ملف آلة.

```bash
cargo run -- --native examples/native.lsn --output native-program
./native-program
cargo run -- --emit-llvm examples/native.lsn --output program.ll
```

الترجمة تمر عبر: `ملف لسان (.lsn) → Lexer → Parser → AST → LLVM IR → Clang → ملف تنفيذي أصلي`.

ليس هذا تغليفًا للمفسّر: الملف التنفيذي الناتج **لا يحتوي على مفسر Rust أو شجرة AST**. تستخدم الطباعة دوال المكتبة القياسية للنظام (`puts`, `printf`) ويستعمل LLVM لتوليد تعليمات المعالج. `--build` القديمة، التي تجمع المفسّر في ملف تنفيذي، باقية مؤقتًا للتوافق ويُفضَّل استخدام `--native`.

## مجموعة الميزات التي يدعمها المترجم الأصلي الآن

- أعداد ذات فاصلة عشرية (`double`) وأرقام لاتينية 0–9؛ متغيرات وإسناد، رياضيات `+ - * / % **`.
- المقارنة والمنطق (`و`، `أو`، `ليس`) والقيم المنطقية.
- النصوص الثابتة والطباعة بالأرقام والنصوص والقيم المنطقية.
- الشروط `إذا/وإلا` والحلقات `بينما` والتحكم `توقف/تابع`.
- دوال رقمية تقبل معاملات رقمية وتعيد رقمًا، ومنها الاستدعاء الذاتي؛ استيراد الملفات من المستوى الأعلى.
- فحص أنواع ساكن أولي، مع رسالة خطأ عربية عندما تُستخدم ميزة غير مدعومة.

## قيود مهمة

- لا يوجد بعد مترجم أصلي للقوائم والقواميس وحلقة `لكل`، والتعامل مع الملفات والشبكات، ولا تجميع النصوص أو الدوال العامة.
- المترجم الأصلي لا ينفذ التحقق الشامل من الأخطاء العددية مثل المفسّر القديم بعد.
- لا يوجد مدير حزم أو نظام أنواع موسع أو جامع نفايات أو مصحح أخطاء للغة.
- Clang ووصلة النظام مطلوبة **أثناء البناء فقط**؛ الملف الناتج يحتاج مكتبات النظام القياسية.
- دعم النظام يعتمد على Clang وبيئة الربط المتوفرة؛ يجري اختبار المسار الأصلي على Linux أولًا.

## فلسفة التطوير

نوسّع خصائص اللغة في المترجم الأصلي تدريجيًا، ثم نستبدل مسار المفسّر القديم عندما يتحقق التكافؤ. لا نسمّي مترجم LLVM الحالي مترجمًا مستقلًا تمامًا عن جميع الأدوات: Clang ما زال يعتمد عليه كواجهة توليد شيفرة الآلة والربط.
