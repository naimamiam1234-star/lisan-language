# لسان 0.6.0 — الإصدار التطويري

تحديث في نواة اللغة وموثوقية التفسير. يتضمن `توقف` و`تابع` مع تحقق نحوي من الموضع، وعامل الأسّ `**` بأولوية واضحة، والصياغة العلمية للأعداد بالأرقام اللاتينية فقط، وحماية من النتائج العددية غير المنتهية، وتوسيع `مدى` بخطوة ثالثة اختيارية، ودوال تحقق مدمجة، وأمر `--test` للملفات.

أضيف ملف `tests/control_flow.rs` و`examples/testing.lsn`. يشمل CI على Linux وWindows وmacOS اختبارات Rust وبرنامج لسان التحققي، وتجميع الملفات التنفيذية للأنظمة الثلاثة. إن بناء الملفات المستقلة يضم مفسّر لسان داخل الملف الناتج ولا يحوّل تعليمات `.lsn` مباشرة إلى تعليمات آلة.

## تعليمات التحقق

```bash
cargo test --all-targets
cargo run -- --test examples/testing.lsn
cargo run -- --check examples/testing.lsn
cargo run -- --build examples/testing.lsn --output lisan-check
./lisan-check
```

لا تغيّر هذه النسخة تراخيص المصدر أو تُنشئ حزم مدير حزم بعد.
