# قواعد لسان (مسودة تنفيذية)

## القيم والأرقام

- الأعداد اللاتينية فقط: `0`, `18`, `3.14`. غير مسموح `١٨` أو `۳` أو `٢٫٥`.
- القيم المنطقية: `صحيح` و`خطأ`؛ والقيمة الخالية `لاشيء`.
- النصوص: `"مرحبا"` مع هروب `\n` و`\t` و`\"` و`\\`.
- القوائم: `[1, 2, "نص"]`، والقواميس: `{"اسم": "سلمى", "العمر": 25}`.

## بناء البرنامج

```text
ليكن س = 10؛
متغير ن = 20؛
إذا (س < ن) { اطبع("نعم")؛ } وإلا { اطبع("لا")؛ }
بينما (س < 15) { س = س + 1؛ }
لكل (عنصر في [1, 2, 3]) { اطبع(عنصر)؛ }
دالة جمع(أ, ب) { أرجع أ + ب؛ }
اطبع(جمع(3, 5))؛
دع شخص = {"الاسم": "منى"}؛
شخص["العمر"] = 25؛
اطبع(شخص["الاسم"])؛
استورد "وحدة.lsn"؛
```

تُقبل `دع` و`ليكن` و`متغير` لتعريف متغير قابل للتغيير. `طالما` و`بينما` مترادفتان. الفهرسة تبدأ من الصفر. لا يدعم الإسناد المباشر سوى `متغير[مفتاح] = قيمة`، ولا يمكن الإسناد إلى فهرسة متداخلة.

## المكتبة القياسية

- الأرقام: `مطلق(س)`, `جذر(س)`, `قرّب(س)`, `أدنى(س، ص)`, `أعلى(س، ص)`.
- النصوص: `نظّف(نص)`, `اقتطع(نص، بداية، نهاية)`, `قسّم(نص، فاصل)`, `ادمج(قائمة، فاصل)`, `استبدل(نص، قديم، جديد)`.
- القوائم: `مدى(نهاية)` أو `مدى(بداية، نهاية)`, `أضف(قائمة، قيمة)`, `احذف(قائمة، فهرس)`.
- القواميس: `مفاتيح(قاموس)`, `قيم(قاموس)`, `احذف(قاموس، مفتاح)`, `يحتوي(قاموس، مفتاح)`.
- الملفات: `اقرأ_ملف(مسار)`, `اكتب_ملف(مسار، نص)`؛ الحجم الأقصى للمحتوى 2 ميغابايت.
- عامة: `طول(شيء)`, `نوع(شيء)`, `نص(شيء)`, `عدد(نص)`.

دالة `أضف` ودالة `احذف` تعيدان قيمًا جديدة، في حين أن `قاموس["مفتاح"] = قيمة` يعدّل المتغير الموجود.

## التحكم في الحلقات (0.6.0)

داخل `بينما` أو `لكل` يمكن استخدام `توقف؛` للخروج من الحلقة الأقرب، أو `تابع؛` للانتقال إلى الدورة التالية. يُرفض استخدامهما خارج الحلقات، كما يُرفض `أرجع؛` خارج الدالة.

```text
لكل (ن في مدى(0، 10)) {
    إذا (ن == 2) { تابع؛ }
    إذا (ن == 6) { توقف؛ }
    اطبع(ن)؛
}
```

## العمليات العددية (0.6.0)

- الأرقام اللاتينية `0-9`، وتُقبل الكتابة العلمية مثل `1e3` أو `2.5E-2`.
- `**` للأسّ وهو يميني التجميع: `2 ** 3 ** 2` تساوي `512`، و`-2 ** 2` تساوي `-4`.
- الأخطاء العددية، مثل النتائج غير المنتهية أو الجذر العددي غير الصالح، تُوقف التنفيذ برسالة واضحة.
- `مدى(بداية، نهاية، خطوة)` يدعم الخطوات الموجبة والسالبة، مثل `مدى(5، 0، -2)`.
- `تحقق(شرط)` و`تحقق_يساوي(فعلي، متوقع)` تُنتجان خطأً عند فشل الاختبار. يمكن تشغيل ملف اختبارات عبر `lisan --test ملف.lsn`، وينتهي البرنامج بحالة خروج غير صفرية عند الفشل.
