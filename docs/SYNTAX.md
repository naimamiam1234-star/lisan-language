# قواعد لسان 0.3.0

كل ملف مصدر UTF-8. الامتداد المقترح `.lsn`. السطور التعليقية تبدأ بـ `#` أو `//`. تنتهي معظم التعليمات بـ `؛` أو `;`؛ لكن الكتل لا تحتاج إلى فاصلة منقوطة بعدها.

## الكلمات الأساسية

| العبارة | دلالتها |
|---|---|
| `دع س = ١؛` | تعريف متغير |
| `س = ٢؛` | تغيير متغير موجود |
| `اطبع(س)؛` | إخراج سطر |
| `إذا (صحيح) {...} وإلا {...}` | تفرع |
| `طالما (شرط) {...}` | تكرار مشروط |
| `لكل (عنصر في قائمة) {...}` | تكرار عبر قائمة أو نص |
| `دالة اسم(أ، ب) {...}` | دالة |
| `أرجع قيمة؛` | إعادة من دالة |
| `صحيح` / `خطأ` / `لاشيء` | قيم أساسية |

تدعم `إذا/اذا` و`وإلا/والا` و`أرجع/ارجع` كمرادفات.

## أنواع البيانات

- أرقام عائمة مزدوجة `5`, `٥`, `۵`, `١٢٫٥`, `12.5`، مع الإشارة السالبة.
- نصوص بين `"..."`؛ تدعم `\\n` و`\\t` و`\\r` و`\\"` و`\\\\`.
- قيم منطقية `صحيح` و`خطأ`، وقيمة فارغة `لاشيء`.
- قوائم `[]` أو `[١، ٢، ٣]`، بما فيها قائمة تحتوي قيمًا من أنواع مختلفة أو قوائم متداخلة.

## القوائم والفهرسة

```lisan
دع أ = [١، ٢، ٣]؛
اطبع(أ[٠])؛          # 1
أ[١] = ٥؛
اطبع(أ)؛             # [1، 5، 3]
اطبع(أ[٢])؛          # 3
دع ب = أ + [٨، ٩]؛
اطبع(طول(ب))؛        # 5
دع ج = [[١، ٢]، [٣، ٤]]؛
اطبع(ج[١][٠])؛      # 3
```

الفهرس عدد صحيح غير سالب يبدأ من الصفر. فهرسة النصوص تحسب **أحرف Unicode** (وليس bytes)، بينما لا يجوز الكتابة على موضع داخل نص. الإسناد إلى قائمة متداخلة غير مدعوم في 0.2.0؛ ويمكن فقط تغيير عنصر قائمة مرتبطة مباشرة باسم متغير.

## التكرار

```lisan
دع نتيجة = ٠؛
لكل (عدد في مدى(١، ٤)) {
    نتيجة = نتيجة + عدد؛
}
اطبع(نتيجة)؛  # 6

لكل (حرف في "لسان") {
    اطبع(حرف)؛
}
```

المتغير في `لكل` محلي لكل دورة. لا توجد بعد أوامر `توقف` أو `تابع`. تستقبل الحلقة القائمة/النص بعد تقييمه **مرة واحدة** في البداية.

## العمليات

- الحساب: `+`, `-`, `*`, `/`, `%`.
- المقارنة: `==`, `!=`, `<`, `<=`, `>`, `>=`.
- المنطق: `&&`, `||`, `!` أو `و`, `أو`, `ليس`، مع تقييم قصير المدى للـ `و` و`أو`.
- مقارنة تساوي القوائم تتم بمقارنة عناصرها. العمليات الحسابية والمقارنة المرتبة تقتصر على الأعداد.
- يربط `+` نصًا بالقيمة المقابلة، أو يضم قائمتين، أو يجمع رقمين.
- كل شرط في `إذا` و`طالما` يجب أن يكون قيمة منطقية.

## الدوال القياسية

| الدالة | الوظيفة | مثال |
|---|---|---|
| `طول(قيمة)` | عدد عناصر القائمة أو أحرف النص | `طول([١،٢])` يعطي 2 |
| `نوع(قيمة)` | اسم النوع بالعربية | `نوع(صحيح)` يعطي `منطقي` |
| `نص(قيمة)` | تحويل قيمة إلى نص | `نص(١٠)` يعطي `"10"` |
| `عدد(قيمة)` | تحويل نص رقمي عربي أو لاتيني إلى عدد | `عدد("١٢٫٥")` يعطي 12.5 |
| `أضف(قائمة، قيمة)` | نسخة جديدة تضم عنصرًا جديدًا | `أضف([١]، ٢)` |
| `مدى(نهاية)` | قائمة 0 إلى نهاية (غير شاملة) | `مدى(٣)` يعطي `[0،1،2]` |
| `مدى(بدء، نهاية)` | قائمة من بدء إلى ما قبل نهاية | `مدى(٢،٥)` يعطي `[2،3،4]` |
| `يحتوي(مجموعة، قيمة)` | اختبار وجود قيمة في قائمة، أو نص داخل نص | `يحتوي([١،٢]، ٢)` |

يمكن للدوال المعرّفة داخل البرنامج أن تحمل أسماء الدوال القياسية فتتجاوزها.

## حدود المفسّر

- لا يوجد `استورد` بعد، ولا إدخال ملفات أو شبكات، ولا الأصناف/القواميس أو الواجهات.
- الدوال تستطيع رؤية المتغيرات العامة ومعاملاتها والمحليات التابعة لها، لكن لا ترى محليات من ناداها.
- دالة يُراد استدعاؤها يجب أن يكون تعريفها قد نُفّذ مسبقًا.
- استخدام `أرجع` خارج دالة ينتج خطأ، والوصول لفهرس خارج الحدود ينتج خطأ.
- وضعت حدود للأداء مبدئية؛ لا تعادل sandbox أمنية.


## استيراد ملف (0.3.0)

```lisan
استورد "math.lsn"؛
اطبع(مربع(٧))؛
```

تُكتب `استورد` في المستوى الأعلى للملف فقط. تُحل المسارات نسبةً إلى موقع الملف الذي يحتوي التعليمة، وليس مجلد التشغيل. تُنفذ الوحدة مرة واحدة عند تكرار استيرادها؛ الاستيراد الدائري يُبلغ عنه بخطأ. هذا استيراد ملفات مصدر، وليس نظام حزم بعد.

لفحص الملفات دون تشغيلها: `lisan --check main.lsn`، ولا يُجري الفحص تحليل أنواع أو اكتشاف جميع أخطاء التنفيذ.
